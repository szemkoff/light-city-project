# Bibliography & Sources

Sources behind the library, graded so readers can see how much weight each one carries.

## Source grades

| Grade | Type |
|---|---|
| **A** | Peer-reviewed research, official filings, primary data |
| **B** | Books, reputable publishers, institutional reports |
| **C** | Trade press, credible industry news |
| **D** | Blogs, unverified claims |
| **E** | Channelings and visions: valuable for inspiration, non-empirical |

Citation style: link inline at the point of use, and note the access date for web sources.
