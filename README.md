# Light City Project

## Vision

**Light City** symbolizes a future collective reality where human civilization operates with higher ethics, compassion, and unity. It represents:

- A literal etheric city — a higher-dimensional construct sometimes called a "city of light"
- A blueprint stored in Earth's energetic field (Gaia's memory)
- A personal vision of a place meant to be built — either physically or energetically — during your lifetime

> *"The city is in the sky until it is in your hands. To build it on Terra, begin building it in hearts. Structures follow spirit."*

## Project Overview

This project serves as a living documentation and development space for manifesting the Light City vision through multiple dimensions:

- **Conceptual**: Philosophical and spiritual foundations
- **Creative**: World-building, design, and artistic expression
- **Technical**: Digital tools, platforms, and experiences
- **Practical**: Community building and real-world implementation

## Branches and Publishing

| Branch / tag | Purpose |
|---|---|
| `main` | Default branch and single source of truth. The Docusaurus site lives in `website/`, documentation in `docs/`. |
| `gh-pages` | Built site served at [szemkoff.github.io/light-city-project](https://szemkoff.github.io/light-city-project/). Generated automatically — do not edit. |
| `archive/emergent-app` (tag) | Snapshot of the earlier Emergent-generated React/FastAPI app (former `Website` branch). |
| `archive/luminous-prototype` (tag) | Snapshot of the single-page luminous design prototype (former PR #1). |

Every push to `main` runs `.github/workflows/deploy.yml`, which builds `website/` (with the `WEB3FORMS_ACCESS_KEY` secret for forms) and publishes it to `gh-pages`. New work goes in short-lived branches off `main` (e.g. `redesign/homepage`), reviewed via pull request, then deleted after merge.
