Privacy policy

How we handle information on this public documentation site.

This site is hosted on GitHub Pages and built with Docusaurus. Like most static sites, hosting providers may process standard server logs (such as IP address and user agent) when you load pages.

If you use the contact form or the founding circle signup, your message is sent through a third-party form provider (Web3Forms). The project does not publish a team email address on this website. There are no account systems or payment flows on this site at this time.

For the open-source repository and issue tracker, see GitHub's privacy statement as it applies to your use of GitHub.
