Light City Goes Public - GitHub Repository and Documentation Site Launch

October 15, 2025 · 2 min read
Light City Project Team
Anchoring Higher-Consciousness Civilization

Today marks a significant milestone: Light City is now publicly accessible through GitHub and has a beautiful documentation website powered by Docusaurus!

What's Launched​

GitHub Repository​

The complete Light City project is now available at github.com/szemkoff/light-city-project

This includes:

  • Complete documentation structure
  • Development roadmaps and planning
  • Research materials and references
  • Asset organization and management
  • Full version control history

Live Documentation Site​

Visit our beautiful Docusaurus-powered site at szemkoff.github.io/light-city-project

Features:

  • Professional navigation and search
  • Organized documentation by category
  • Mobile-responsive design
  • Dark mode support
  • Fast, modern browsing experience

What This Means​

Light City is no longer a private vision—it's now an open project ready for:

  • Collaboration - Others can contribute and build upon the foundation
  • Visibility - Reaching people who resonate with the vision
  • Professional Development - Proper version control and project management
  • Community Building - Infrastructure for a growing team
